# xiaohongshu-cover-copy

A Codex skill that turns an existing video, transcript, topic, or brand reference into a Xiaohongshu-ready package: a 3:4 cover, compliant title, natural long-form copy, relevant topic tags, character counts, and saved deliverables.

The repository contains no user logos, videos, customer cases, or generated media.

## Install

```bash
git clone https://github.com/smallsmallfang/xiaohongshu-cover-copy-skill.git ~/.codex/skills/xiaohongshu-cover-copy
```

## Use

```text
Use $xiaohongshu-cover-copy to turn this video or topic into a ready-to-publish Xiaohongshu package.
```

The skill generates files only. Uploading or publishing to a Xiaohongshu account requires separate explicit authorization.
